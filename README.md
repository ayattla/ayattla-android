# آيات تتلى — تطبيق أندرويد الأصلي

تطبيق أندرويد أصلي (Kotlin وJetpack Compose، بلا WebView) لموقع [ayattla.com](https://ayattla.com)، على خطى تطبيق الآيفون.

- **القرآن:** 114 سورة بالرسم العثماني من Tanzil حرفيًا، فهرس السور والأجزاء، البحث، متابعة القراءة، حجم الخط، حفظ الآيات.
- **التلاوة:** من EveryAyah آية بآية مع البسملة، تعمل في الخلفية وعلى شاشة القفل، بسرعة وتكرار.
- **الأذكار:** أبواب حصن المسلم بعداد واهتزاز وحفظ يومي.
- **الأدوات:** المسبحة، مواقيت الصلاة، القبلة، التاريخ الهجري، الزكاة، بنفس معادلات الموقع (اختبارات مطابقة في `app/src/test`).
- **اصنع:** بطاقات الآيات بثلاثة مقاسات وثلاث خلفيات، حفظ في الصور ومشاركة.

## البناء

- GitHub Actions مع كل دفع: `tools/prepare.sh` يبني حزمة المحتوى ويجلب الخطوط، ثم الاختبارات، ثم ملف المتجر ونسخة التجربة.
- البناء الاحتياطي والتوقيع النهائي للمتجر: `build.sh` على خادم الموقع. مفتاح الرفع لا يُرفع إلى هذا المستودع أبدًا.
