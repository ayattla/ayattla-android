# آيات تتلى — تطبيق أندرويد

تطبيق أندرويد لموقع [ayattla.com](https://ayattla.com)، يفتح الموقع ملء الشاشة (Trusted Web Activity) بعد التحقق من ملف `/.well-known/assetlinks.json`.

- المعرّف: `com.ayattla.app`
- البناء: GitHub Actions مع كل دفع إلى `main` (الملفات الناتجة في صفحة التشغيل لمدة 14 يومًا).
- البناء الاحتياطي والتوقيع النهائي للمتجر: `build.sh` على خادم الموقع، حيث يُحفظ مفتاح الرفع. المفتاح لا يُرفع إلى هذا المستودع أبدًا.
